# Surefire Social Lead Clipper — 浏览器插件使用说明

本插件专门用于**解决 Facebook Group 严格的 CSP（内容安全策略）及 Mixed Content 跨域拦截**，让管理员在 Facebook 浏览时一键高亮划选客户帖子，直接同步至 Surefire 水暖工作台。

---

## 🚀 快速安装方法（仅需 10 秒）

1. 打开 Google Chrome 或 Edge 浏览器，在地址栏输入：
   `chrome://extensions/`
2. 在右上角开启 **「开发者模式」(Developer mode)**。
3. 点击左上角的 **「加载已解压的扩展程序」(Load unpacked)**。
4. 选择本项目中的 `chrome-extension` 文件夹即可完成安装！

---

## 📌 日常使用方式

1. **日常浏览**：在 Facebook Group（如 Warrington, Liverpool, Cheshire 等水暖手艺人或社区群组）中发现潜在客户提问。
2. **高亮选中**：用鼠标选中客户发布的正文内容。
3. **右键发送**：点击鼠标右键，选择 **「🚀 发送到 Surefire 水暖工作台」**。
4. **实时反馈**：网页右上角立刻弹出绿色通知：
   `✅ 已成功同步到 Surefire 工作台！区域: IN_AREA · 意向评分: 84/100`
5. **后台工作台处理**：回到 Surefire 工作台（`http://localhost:3000/admin/social-leads` 或您的 Vercel 域名），一键复制地道英式英语草稿并跟进预约！
